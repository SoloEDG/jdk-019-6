# Vectora 矢量路径工具

安装：Node.js 22 环境下执行 `npm ci`。

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:8119。

## 位图描摹（Bitmap → Vector）

工具栏 `trace` 打开描摹面板，选择一张位图（双色标志效果最佳）后在后台 Worker 中描摹，期间可继续编辑文档，也可随时取消：

- **Colors**：中位切分 + 最小方差分裂的颜色归并；调色板可点选哪些颜色作为背景（四角自动识别，透明像素始终为背景）。
- **Denoise**：预乘 alpha 的可分离盒式模糊去噪。
- **Precision**：误差预算（px）。先按预算做 Douglas-Peucker 多边形简化，再在预算内做 Schneider 最小二乘三次贝塞尔拟合——节点只花在最需要的地方，不按固定间隔抽点。
- **Keep details ≥**：小于该面积的斑点被丢弃、小孔被填平，效果实时反映在画板预览上。
- **Corners**：超过该转角的顶点保留为尖角节点，其余位置平滑拟合。

轮廓沿像素边界追踪（前景 4 连通、背景 8 连通）：同色孤立区域各自独立成形，绝不被错误连接；相邻色层共享同一几何边界，层间无缝。内轮廓（含透明洞口）作为子路径随形状一起生成，按 evenodd 规则填充。

预览确认后按颜色分组、按区域大小自底向上堆叠生成可选图层；节点编辑、填充修改与 SVG 导出都直接作用于生成的曲线路径。

## 测试

- `npm run test:unit`：描摹管线单元测试（颜色归并、洞口/孤岛识别、去斑规则、尖角保留、误差预算下的节点数）。
- `npm run test:e2e`：端到端测试（需先 `npm run build` 且 `npx playwright install chromium`）。
